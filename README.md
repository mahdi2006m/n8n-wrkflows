# 🚀 ورک‌فلوهای n8n

مجموعه‌ای منتخب از **ورک‌فلوهای n8n** آماده‌ی تولید برای اتوماسیون، هوش مصنوعی، APIها، وب‌اسکرپینگ، اعلان‌ها و بهره‌وری.

این مخزن شامل ورک‌فلوهای قابل استفاده‌ی مجدد و مستند است که می‌توانید آن‌ها را مستقیماً به نمونه‌ی n8n خودتان وارد کنید.

# 🚀 شروع کار

## 1. کلون کردن مخزن

````bas  
git clone https://github.com/yourusername/n8n-workflows.git
````

2. نمونه‌ی n8n خود را باز کنید

به

Import Workflow

بروید

3. یک ورک‌فلو انتخاب کنید

یکی از فایل‌های JSON را وارد کنید.

4. پیکربندی اعتبارنامه‌ها (Credentials)

بیشتر ورک‌فلوها به اعتبارنامه‌هایی مانند موارد زیر نیاز دارند:

- OpenAI
- Telegram
- PostgresSQL

<!-- - GitHub
- Google
- Slack
- SMTP -->

قبل از اجرای ورک‌فلو، آن‌ها را با اعتبارنامه‌های خودتان جایگزین کنید.

5. اجرای ورک‌فلو

ورک‌فلو را فعال کنید و لذت ببرید 🎉

## 📁 نمونه‌ی پوشه‌ی ورک‌فلو

هر ورک‌فلو در حالت ایده‌آل باید به این شکل باشد:

```
ai-physics-tutor
├── ai-physics-tutor.json
└── README.md
```

# 🔑 اعتبارنامه‌ها (Credentials)

اعتبارنامه‌ها در این مخزن **گنجانده نشده‌اند**.

باید اعتبارنامه‌های خودتان را داخل n8n ایجاد کنید.

نمونه‌ها عبارتند از:

- OpenAI API Key
- Telegram Bot Token

مشارکت‌ها خوش‌آمدند.
